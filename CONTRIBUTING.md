# Contributing to LKHODRA (الخضرة والغلة)

Thank you for your interest in contributing to **LKHODRA**, the Moroccan Fruits, Vegetables, Seasons & Clinical Benefits Encyclopedia!

## How to Contribute
1. Fork the repository and create a feature branch (`git checkout -b feat/new-terroir-species`).
2. Add or refine Moroccan produce entries in `src/data/produce.ts` with verified Darija regional names (`oriental`, `chamal`, `centre`, `sud`), peak months (`1–12`), and peer-reviewed nutritional benefits.
3. Run `npm run test` and `npm run build` to ensure all tests and TypeScript checks pass.
4. Submit a Pull Request attributing your additions clearly.
